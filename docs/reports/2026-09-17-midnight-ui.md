# 夜间创作室 UI 更新记录

## 已实现

- 移除代码绘制的 SVG 人物、CSS 拱窗与装饰背景；替换为 17 张生图产出的 PNG。
- 乔布斯与小黑各六种表情，系统精灵平静/思考两种；其余系统情绪复用平静图。
- 主菜单采用左侧标题和纵向菜单、右侧双人物；游戏采用大立绘、底部宽对话框、姓名牌、底缘快捷按钮。
- 输入区、设置、存档、交付卡和文档阅读器复用同一套生成框体；文字保留为 DOM，支持选择、滚动与键盘。
- 公开美术路由只允许内置 PNG 清单，不暴露提示词文件、任意路径或会话资源。自定义图片不可用时回退到对应内置图。
- 保留现有同步、交接顺序、输入时机、存档和设计闭合规则，没有增加模型服务、浏览器密钥或运行时生图成本。

## 已实测

- `npm run check`、`npm test`、`npm run build` 通过，31 项自动测试全部通过；新增用例核对全部素材 PNG 签名、返回类型和任意路径拒绝。
- `node --check web/game.js` 通过。
- 17 张原始素材尺寸/透明通道读取完成：除场景背景外，人物和 UI 皮肤均有实际透明通道；生成原件原样复制入仓库。
- Codex 内置浏览器离线夹具：1280×720 主菜单和对话舞台，720×900 分栏布局、设置、回复框；实际查看表情、姓名、按钮和正文。
- 实际点击检查：读档 → 乔布斯接纳/转接 → 小黑登场/提问 → 输入并发送样例回复 → 小黑告别 → 系统交付 → 打开 Markdown 阅读器。刷新后从存档恢复到小黑对应台词。
- 浏览器控制台没有 error/warn。截图保存在 `docs/screenshots/`，对话及设置截图明确标注“离线界面测试（无模型）”；主菜单截图随下述修订更新为本地运行页面。
- 本地正式服务已启动新代码，实际页面显示新主菜单和“已连接 · Codex 原任务”，控制台没有 error/warn；保留主菜单供查看，没有从正式页面发送测试输入。
- 按后续截图反馈，删除主菜单标题下介绍、按钮下两行文案、底部流程文字，双人物封面改为现有系统精灵生成图；1280×720 和 720×900 均已实际查看。此项只改 HTML/CSS 与预览，不改变对话逻辑。
