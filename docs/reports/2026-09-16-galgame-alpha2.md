# GalGame alpha.2 交付记录 · 2026-09-16

## 用户决定与验证边界

用户明确停止继续人工编号同步测试：“不用验证了，我感觉数据已经可以同步了”。保留此前 Codex 原任务的双向、原窗口可见、正式回复、顺序、确认后重连证据，不再发送新的人工测试编号。完整 10 轮、两个真实任务隔离、发送途中真实故障等未完成项目保持未验证。此决定允许继续实现，不等于把兼容认证改为通过。

## 已实现

- 版本化剧情合同，角色、情绪、顺序、图片归属、文档关联校验。每轮先暂存，再核对原任务正式回复；正文不一致保留原文并报错。
- 系统、乔布斯、小黑的 GalGame 主界面和六种内置矢量情绪立绘。逐字播放、速度设置、立即显示、点击继续；交接中间不打开输入框。
- 图片设置、当前宿主提供的 PNG/JPEG/WebP 资源、请求失败/图片解码失败回退内置图；无额外模型调用。
- 自动草稿、读档、播放位置、页面控制权、显式接管、断线和长等待提示。存档只登记显式配对任务。
- 小黑告别后由系统交付真实 Markdown；安全文本排版、下载、显式确认后返回原任务开发。最终闭合继续由 Skill 检查；程序校验闭合声明和文档，不声称自动判断产品质量。
- 删除只清除网页专属缓存与草稿。已在原任务中链接的图片和方案放入 published，保留文件，避免原任务里的链接失效。
- 真正 MCP stdio 服务、等价 CLI、当前任务启动器及 Skill 安装器。安装器备份旧版并记录本机路径，不自动改全局 MCP。
- 既有 /verifier 诊断入口保留，根页面改为 GalGame。

## 未验证或限制

- 新剧情协议在真实 Codex 中完整跑完一次四阶段产品审查，尚未实测；当前真实接入证据与离线剧情 UI 证据分别记录。
- 用户宿主实际生图到双角色图片交接的整条链路尚未重新实测。
- Claude Code 无现有可附着环境，未实现适配。macOS 未实测；国内其他 Agent 未列兼容。
- 多真实原任务隔离、真实发送中断等兼容验收未完成，正式认证列表仍为空。
- MCP SDK 与 stdio 服务已实测，未声称此桌面任务已经动态加载 MCP；当前可直接使用 CLI 桥接。
- Agent 不按 Skill 输出结构化正式正文时，网页会提示返回原任务处理，无法保证不同模型都能完美遵守人设。
- 已删除网页剧情不会从全部宿主历史自动重建；重新启动从当前进度开始，以原 Agent 记忆为准。
- Markdown 阅读采用安全的常用块排版，内嵌 HTML、远程图片和可执行链接不会运行。

本版使用开发分支发布，保留原 Skill 的 main；不会把实验适配写成跨 Agent 通用安装支持。
