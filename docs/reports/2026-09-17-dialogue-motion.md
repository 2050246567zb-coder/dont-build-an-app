# 口语台词与立绘过渡调整

## 已实现

- 主 Skill、对话参考和角色参考都强调当面聊天：先接具体的话，再表达这个角色的判断；不把后台审查表、过关回执或产品术语直接当台词。
- 系统精灵好奇、亲切、利落；乔布斯围绕体验和取舍追问；小黑以第一人称表达使用麻烦。补充自拟对话校准，不冒充历史引语，不靠重复语气词制造人物感。
- 保留原有证据、角色交接、用户作决定、小黑不给答案与文档闭合规则。文档保持可执行，口语调整只作用于对话。
- 等待台词尾部以固定占位宽度循环显示 `.` → `..` → `...`，1.5 秒一轮，不假报生成进度；正文到来或退出对话后停止。
- 内置立绘、生成图、精灵 PNG 点击表情都先解码再切换。整个角色表面先淡出 120ms，再淡入 160ms；旧图在新图加载时保持可见。使用既有缓动，不引入库或生成新素材。
- 快速切换只接受最新请求；加载失败保留当前图并按剧情逻辑回退。支持减少动态效果，立绘直接切换、圆点静止。

## 已验证

- TypeScript 构建、Skill 文件校验通过；原 40 项自动检查通过，新增发布器跨宿主回归检查与相关 MCP/WorkBuddy 检查再次通过，共 41 项。
- 在真实浏览器的离线 UI 夹具中，从系统进入乔布斯、再交接给小黑；刷新恢复原台词位置。
- 等待时实际采样到了圆点透明度 `1,0,0`、`1,1,0`、`1,1,1` 三种状态。
- 换立绘时实际读到淡入动画 160ms、透明度约 0.55；动画结束为 1，角色图与当前人物一致。
- 并发切图返回旧请求取消、新请求成功，最终保留小黑；故意请求不存在的图片后原图保持、透明度为 1。该 404 是主动故障测试。
- 模拟减少动态效果后没有运行中的立绘动画，透明度为 1；随后撤销模拟并刷新，测试没有留下浏览器设置改变。
- 两个本机 Skill 安装位置已更新并留备份；没有改写已发出的原聊天记录。

## 尚未证明的效果

人物是否足够自然仍需真实用户连续使用判断。此处验证了指令、示例、静态约束与界面行为，没有把固定台词的 UI 演示当作不同模型的人设一致性评测，也没有承诺每种模型都能呈现相同口吻。
