# 角色场景、整页皮肤与输入避让

日期：2026-09-17。

## 已实现

- 原先只有系统精灵的 CSS 选择器参与输入框避让；现改为所有角色共用的左右安全区域。输入与交付面板在右，立绘在左；小于 550px 时改为上下排列。面板有最大高度与内部滚动，不覆盖底部对话。
- 主题按当前播放片段切换：系统精灵为夜间创作室，乔布斯为生成的 Apple 设计办公室意象与银白界面，小黑为侦探动画黑影登场意象的黑色放射背景与黑白切角界面。用户回答和思考期间保留当前角色主题，主菜单恢复系统主题。
- 主题覆盖整个文档：顶栏、姓名牌、台词、输入、快捷按钮、设置、存档、文档阅读、交付、删除/开发确认、提示与焦点控件。台词顺序、原会话同步和设计闭合不变。
- 新增四张内置生成 PNG，两张面板具有真实透明通道。提示词保存在 `web/assets/midnight/role-theme-prompts.json`。不增加运行时生图、模型服务、API Key 或新依赖。
- 背景交叉渐变，角色避让缓动，控件换肤淡入；按钮悬停/按下、输入焦点、选项反馈、菜单与卡片入场、弹窗进退场均有对应动效。原立绘的预加载淡出/淡入与等待省略号继续保留。
- 主题动画使用真实控件，不使用阻碍快速点击的全页截图。减少动态效果时停用动画；不支持 CSS 离散过渡的浏览器保留面板入场降级。

## 已实测

- `npm run check`、`npm test`、`npm run build` 通过，54 项测试通过；所有新增生成素材通过 HTTP PNG 路由检查。前端语法与 Skill 校验通过。
- Windows Codex 内置浏览器，通过无模型 `ui-fixture.ts` 的主题模式检查系统 → 乔布斯提问 → 乔布斯告别 → 小黑提问 → 小黑告别 → 系统交付。没有向真实 Agent 发送测试消息。
- 720 × 950 下三种角色的输入避让、1440 × 900 下乔布斯避让均无水平重叠/水平溢出。500 × 900 下动画结束后小黑位于输入框上方；该尺寸允许整页滚动。
- 乔布斯的设置、存档、回看阅读器实际打开；其他确认框及提示的计算皮肤均为 jobs-panel。小黑的设置也跟随黑白主题；交接后系统交付卡片恢复原蓝金皮肤。
- 收起/重新打开输入框，浏览器记录到面板 320ms 与人物 480ms 的动画。人物位置使用 `cubic-bezier(.16,1,.3,1)`。模拟减少动态效果后，运行中动画数为 0，位移过渡为 0s。
- 最终实现连续点击角色交接与「立即显示」后，下一角色正文完整出现，输入/文档正常开放。交付卡片与立绘互不重叠，也未盖住底部台词；文档实际可打开。最后浏览器错误/警告日志为空。
- 本地 Codex / WorkBuddy 已安装的 Skill 参考同步；当前维护任务的统一网页服务已重启读取新版静态路由。

## 边界与复现

此报告验证前端呈现，不能作为新增宿主同步认证；macOS、其他浏览器的性能和不支持离散过渡时的视觉降级尚未实机测试。本轮没有重新测试 WorkBuddy 原任务模型发送。其他仍运行旧版后台的入口需从对应原任务重新启动；也可使用已更新的统一入口选择已有存档。原数据目录不变。

PowerShell：

```powershell
$env:GALGAME_FIXTURE_THEMES='1'
$env:GALGAME_FIXTURE_DELAY_MS='8000'
node --import tsx scripts/ui-fixture.ts .galgame/theme-check
```

从输出的测试链接进入，用三个普通回答依次推进所有角色。该目录只有演示内容，不连接任何模型。常规夹具默认仍保持原有流程，不设置主题变量即可。
